# Results

Generated by the code in this repository.

- `summary.json`, `budget.json`, `audit_summary.json`, `bench_speed.json`, `int8_method.json`, `data_verify.json`, `env.json` - run summaries
- `tables/` - result tables (CSV)
- `figures/` - result figures (PNG)
- `demo/` - demo pipeline outputs
- `runs/<arch>-<regime>-<seed>/` - per-run metrics (JSON/CSV)

**Not uploaded because of size:** model checkpoints (`*.pt`), ONNX exports (`*.onnx`) and raw logit arrays (`*.npy`) of each run
(about 300 MB in total, GitHub limits files to 100 MB and repos should stay small).
Only one small sample model is kept: `runs/mnv3s-soft-s0/onnx/int8.onnx`.
Re-create the rest with `scripts/run_matrix.py` and `scripts/eval_all.py`.
